Quick Start

Get started in 3 simple steps

Bash - Start Main Application 
# Terminal 1: Start main annotation interface
npm run dev
# Access at: http://localhost:5002/image-collector.html
Bash - Start AI Backend (Optional) 
# Terminal 2: Start AI backend for auto-annotation
pip install -r requirements.txt
python ai_backend.py
# Swagger UI: http://localhost:8000/docs
Python - API Integration 
import requests

# Auto-annotate an image
files = {'file': open('image.jpg', 'rb')}
data = {'model': 'yolov8n', 'confidence': 0.25}

response = requests.post(
    'http://localhost:8000/detect',
    files=files,
    data=data
)

detections = response.json()['detections']
print(f"Detected {len(detections)} objects")
